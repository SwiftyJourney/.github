SwiftyJourney is where [Juan Dorado](https://github.com/jfdoradotr), a Senior iOS Engineer from Mexico,
shares what he learns building iOS apps: architecture, testing, Swift Concurrency, and how AI agents
fit into real Swift codebases. The repos here are the code behind the articles.

### 🤖 Agent skills for iOS

Skills for Claude Code and other agents that write and review Swift the way a senior team would.

| Skill | What it covers |
| --- | --- |
| [ios-architecture-expert-skill](https://github.com/SwiftyJourney/ios-architecture-expert-skill) | Modular, testable apps: composition root, protocol boundaries, Swift 6 concurrency |
| [requirements-engineering-skill](https://github.com/SwiftyJourney/requirements-engineering-skill) | Vague requirements into testable specs: BDD narratives, use cases, payload contracts |
| [swift-language-expert-skill](https://github.com/SwiftyJourney/swift-language-expert-skill) | Value semantics, generics, collections, strings, concurrency |
| [swift-testing-expert-skill](https://github.com/SwiftyJourney/swift-testing-expert-skill) | Swift Testing, XCTest migration, test doubles, deterministic async tests |
| [swiftui-expert-skill](https://github.com/SwiftyJourney/swiftui-expert-skill) | State, composition, performance, animations, accessibility, Liquid Glass |
| [swiftui-uikit-interop-skill](https://github.com/SwiftyJourney/swiftui-uikit-interop-skill) | UIHostingController, representables, coordinators, lifecycle migration |
